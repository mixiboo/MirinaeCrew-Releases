# 미리내 크루

Windows · Android 공식 설치 파일과 업데이트를 배포하는 저장소입니다.

## 다운로드

[최신 버전 다운로드](https://github.com/mixiboo/MirinaeCrew-Releases/releases/latest)

- Windows: `MirinaeCrew-windows-x64.zip`을 새 폴더에 모두 풀고 `mirinae_crew.exe`를 실행하세요.
- Android: `MirinaeCrew-android.apk`를 기존 앱 위에 설치하세요.

0.8.0부터 앱 실행 후 새 버전을 안내하며, 설정에서도 업데이트를 확인할 수 있습니다. Windows는 설치 준비 후 앱을 닫고 파일을 교체한 뒤 다시 실행합니다. Android는 시스템 설치 화면에서 설치를 확인해야 합니다.

## 다음 버전 배포

1. 앱 버전과 빌드 번호를 올려 Windows ZIP과 서명된 APK를 만듭니다.
2. `v0.8.0+9`처럼 버전과 빌드 번호를 포함하는 태그로 릴리스 초안을 만듭니다. 다음 빌드 번호는 이전보다 커야 합니다.
3. 두 파일을 각각 `MirinaeCrew-windows-x64.zip`, `MirinaeCrew-android.apk`라는 이름으로 첨부합니다.
4. 모든 첨부 파일의 업로드가 끝난 뒤 정식 릴리스로 공개하고 최신 버전으로 지정합니다.

앱은 GitHub의 파일 크기와 SHA-256을 확인한 뒤 설치를 준비합니다. 초안과 사전 릴리스는 앱에 배포되지 않습니다.

이 저장소에는 설치 파일과 변경 안내만 올립니다. 앱 소스, 크루 데이터, Firebase 서버 인증 키, Android 서명 키는 포함하지 않습니다.
